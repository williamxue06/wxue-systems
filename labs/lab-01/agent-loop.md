# Lab 1 Agent Loop

## Gather context
Claude first checked which tools were installed on my computer, including Git, GitHub CLI, Python, and Streamlit. It also checked whether I was logged into GitHub and looked at the project folder to understand what was already there.

## Act
Claude set up Git to use my GitHub login, created my course repository, and uploaded the starter files. It then helped build the apps by creating the Python files and installing the tools needed to run them.

## Check
Claude checked its work by running the to-do app and checking for errors. It also used automated tests to check whether adding, completing, deleting, and saving tasks worked, and it reported that all 12 checks passed.
